# PC Build Budget Checker - Java

A simple Java console app to check if you can build a Gaming PC in your budget.

### Features
- Uses Constructor & OOP concept
- Takes user input for 6 components
- Calculates total cost and compares with budget

### Components
- CPU: Ryzen 5 5600
- GPU: RTX 3060
- RAM: Corsair Vengeance
- Motherboard: MSI B550M
- SSD: Crucial P3 500GB
- PSU: Corsair CV550

### How to Run
javac Pcbuild.java
java Pcbuild
